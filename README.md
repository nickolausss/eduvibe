# EduVibe — ИИ-генератор сценариев внеурочных занятий

![Python](https://img.shields.io/badge/Python-3.9+-blue)
![Django](https://img.shields.io/badge/Django-4.2-green)
![YandexGPT](https://img.shields.io/badge/AI-YandexGPT%205.1%20Pro-purple)
![License](https://img.shields.io/badge/License-MIT-yellow)

**EduVibe** — это AI-сервис, который генерирует **полные сценарии внеурочных занятий** для классных руководителей и педагогов-организаторов за 40–120 секунд. Вместо 2–3 часов ручной подготовки учитель заполняет короткую форму и получает готовый план с легендой, этапами, репликами учителя, вопросами и ответами детей, чек-листом подготовки и домашним заданием.

Сервис **полностью соответствует ФГОС НОО/ООО/СОО, ФОП, Федеральной рабочей программе воспитания (ФРПВ) и ФАОП для детей с ОВЗ**. Использует **YandexGPT 5.1 Pro** и технологию **RAG (Retrieval-Augmented Generation)** для повышения качества сценариев на основе ранее созданных.

## Как готовились к проекту

### 1. Исследование проблемы

Классные руководители в российских школах тратят **2–3 часа** на подготовку одного внеурочного занятия. При нагрузке 2–3 занятия в неделю это до **9 часов** только на подготовку. По данным исследований (Шилкова М.С., Чащина Н.А., 2025), использование ИИ в подготовке к урокам является **«действенной мерой профилактики профессионального выгорания»**.

Мы опросили **15 классных руководителей** (1–11 классы) из школ Москвы, Санкт-Петербурга и регионов. Основные боли:

| Проблема | % респондентов |
|----------|----------------|
| Нехватка времени на подготовку | 93% |
| Сложность придумать легенду и игровые механики | 80% |
| Неуверенность в соответствии ФГОС | 67% |
| Однообразие форматов (только классные часы) | 60% |
| Нет готовых материалов для печати | 53% |

### 2. Изучение нормативной базы

Перед проектированием были изучены:

- **Федеральный закон № 273-ФЗ** «Об образовании в РФ»
- **ФГОС НОО** (приказ № 286), **ФГОС ООО** (№ 287), **ФГОС СОО** (№ 732)
- **ФОП НОО/ООО/СОО** (приказы № 372, 370, 371 от 18.05.2023)
- **Федеральная рабочая программа воспитания** (ФРПВ, 11 модулей)
- **ФАОП** для детей с ОВЗ (приказы № 1023, 1025, 1026)
- **Профессиональный стандарт «Педагог»** (приказ Минтруда № 544н)
- **СанПиН 2.4.3648-20** и **СП 2.4.3648-20**
- **Письмо Минпросвещения № ТВ-1290/03** о внеурочной деятельности

### 3. Анализ конкурентов

| Продукт | Сильные стороны | Слабые стороны |
|---------|-----------------|----------------|
| **Сбер Айзек** | Генерация планов уроков | Нет внеурочки по ФГОС, нет легенд и геймификации |
| **Яндекс.Учебник** | Встроенный AI для предметов | Только предметные уроки, не воспитательная работа |
| **Гигачат / ChatGPT** | Общая генерация | Нет методической структуры, экспорта PDF/DOCX |
| **Готовые шаблоны** | Соответствие ФГОС | Не адаптируются под конкретный класс и тему |

**Вывод:** ниша AI-генерации сценариев внеурочной деятельности с полным соответствием ФГОС **свободна**.

## Как собирали данные

### 1. Методическая база

- Проанализированы **50+ реальных сценариев** внеурочных занятий из открытых источников (единыйурок.рф, разговорыоважном.рф, копилкауроков.рф)
- Выделены **обязательные структурные элементы**: легенда, цели (воспитательная + практическая + Soft Skills), этапы, рефлексия, риски, чек-лист
- Составлена **карта 8 направлений × 8 форматов × 3 возрастные группы** (1–4, 5–8, 9–11 классы)

### 2. Промпт-инжиниринг

- Разработано **6 последовательных промптов** к YandexGPT 5.1 Pro
- Каждый промпт протестирован на **20+ различных комбинациях** параметров
- Промпты **валидированы методистом** с 15-летним стажем
- Внедрён **RAG** (Retrieval-Augmented Generation) — поиск похожих успешных сценариев в базе и добавление их как примеров в промпт

### 3. Технические данные

- **YandexGPT API:** модель `yandexgpt-5.1/latest`, до 8000 токенов на запрос
- **Эмбеддинги:** YandexGPT Embeddings API + хеш-векторы как фолбэк
- **Векторный поиск:** косинусное сходство через NumPy
- **Логирование:** все AI-запросы фиксируются в `LLMRequestLog`

## Как писали код

### 1. Архитектурные решения

| Решение | Почему |
|---------|--------|
| **Django 4.2** | Самый популярный Python-фреймворк, отличная ORM, админка из коробки |
| **SQLite** | Достаточно для MVP, не требует отдельного сервера БД |
| **Vanilla JavaScript** | Без React/Vue — проект должен быть лёгким и быстрым |
| **CSS Custom Properties** | Тёмная тема и адаптивность без препроцессоров |
| **Quill.js** | Лучший WYSIWYG-редактор для редактирования сценариев |
| **Chart.js** | Лёгкие графики для статистики |
| **ReportLab + python-docx** | Экспорт в PDF и DOCX с кириллицей |
| **6 AI-запросов в 2 волны** | Волна 1: структура → этапы (последовательно). Волна 2: 4 запроса параллельно для скорости |

### 2. Процесс разработки

- **Неделя 1:** проектирование моделей данных, форма-конструктор
- **Неделя 1:** AI-генерация, промпт-инжиниринг, валидация
- **Неделя 1:** календарь, загрузка планов, версионирование
- **Неделя 2:** фронтенд, адаптивность, тёмная тема, экспорт
- **Неделя 2:** RAG, эмбеддинги, векторный поиск
- **Неделя 2:** тестирование, отладка, документация

### 3. Баги, которые были исправлены

| Баг | Как исправили |
|-----|---------------|
| Запросы 3–6 получали пустые контексты | Двухфазная генерация: сначала этапы, потом параллельно 4 запроса |
| `year/month` в календаре падали при `?year=abc` | `try/except` + нормализация |
| `toggleTheme()` дублировалась | Убрали инлайн-версию, оставили в `main.js` |
| `validate_scenario` падал при битом JSON | Фолбэк на исходный dict вместо `json.loads` |
| Embeddings API возвращал ошибку 400 | Добавлен хеш-вектор как надёжный фолбэк |

## Функциональность

### 🔹 Для учителя

- **Создание сценария:** 4-шаговая форма, 15+ полей, подсказки
- **AI-генерация:** 6 запросов к YandexGPT, результат за 40–120 секунд
- **14 разделов:** название, легенда, цели, 5–7 этапов, рефлексия, материалы, адаптация, риски, оценка, советы, сценарий ведущего, чек-лист, домашнее задание
- **Редактирование:** WYSIWYG Quill.js для каждого раздела
- **Экспорт:** PDF для печати, DOCX для редактирования
- **Шаринг:** персональная ссылка + QR-код
- **Календарь:** привязка к датам, загрузка планов (TXT, DOCX, PDF, PPTX)
- **Презентация:** полноэкранный режим слайдов

### 🔹 Методическая ценность

- **Полное соответствие ФГОС** (НОО/ООО/СОО) и ФРПВ
- **8 направлений воспитания × 8 форматов**
- **Адаптация для детей с ОВЗ** по ФАОП (5 нозологических групп)
- **Формирующее оценивание** (критерии, самооценка, взаимооценка)
- **Здоровьесбережение** (физкультминутки, гимнастика для глаз по СанПиН)
- **Функциональная грамотность** в домашнем задании

### 🔹 Технические фишки

- **RAG:** поиск похожих сценариев, качество растёт с базой
- **Версионирование:** до 50 версий, восстановление, сравнение
- **Пул API-ключей:** round-robin балансировка
- **Retry-логика:** до 10 попыток при ошибках
- **4-уровневый JSON-парсер:** восстановление битых ответов AI
- **Валидация модератором:** проверка контента перед сохранением
- **Лимиты:** 20 генераций/день по IP+UserAgent

## Как запустить у себя

### 1. Клонировать репозиторий

```bash
git clone https://github.com/nickolausss/eduvibe.git
cd eduvibe
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Настроить переменные окружения

#### Создать файл .env в корне проекта:

env

```python
SECRET_KEY=your-secret-key-here
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
YANDEX_API_KEY=your-yandex-api-key
YANDEX_PROJECT_ID=your-yandex-project-id
YANDEX_PROMPT_ID=your-prompt-id
YANDEX_API_KEYS=key1,key2,key3
```

#### Где взять ключи:

Зарегистрироваться в Yandex Cloud

Создать сервисный аккаунт с ролью ai.languageModels.user

Создать API-ключ

Узнать PROJECT_ID (Folder ID) в настройках облака

### 5. Применить миграции

```bash
python manage.py migrate
```

### 6. Создать суперпользователя (для админки)

```bash
python manage.py createsuperuser
```

### 7. Собрать статику

```bash
python manage.py collectstatic --noinput
```

### 8. Создать эмбеддинги для RAG (если есть существующие сценарии)

```bash
python manage.py embed_all_scenarios
```

### 9. Запустить сервер разработки

```bash
python manage.py runserver
```

Открыть в браузере: http://127.0.0.1:8000

Админка: http://127.0.0.1:8000/admin/

## Выводы

### Что сделано

**EduVibe** — это полностью готовый к использованию AI-сервис для классных руководителей. Решена главная проблема: **катастрофическая нехватка времени** на подготовку внеурочных занятий.

### Чем проект поможет учителям

1. **Экономия 2–3 часов на каждом занятии.** Учитель заполняет форму за 2 минуты и получает готовый сценарий за 40–120 секунд.

2. **Уверенность в соответствии ФГОС.** Промпты разработаны с учётом всех актуальных нормативных документов: ФГОС, ФОП, ФРПВ, ФАОП, СанПиН. Сценарий содержит воспитательные цели, личностные и метапредметные результаты, формируемые УУД.

3. **Методическое разнообразие.** 8 направлений воспитания × 8 форматов = 64 комбинации. Учитель может чередовать классные часы, квизы, игры, дебаты, киноклубы — вместо однообразных «бесед о...».

4. **Готовые материалы для печати.** Сценарий можно распечатать (PDF) или открыть на планшете (QR-код). Чек-лист подготовки, прямая речь учителя, вопросы и предполагаемые ответы детей — всё готово к использованию.

5. **Инклюзивность.** Адаптации для детей с ОВЗ (слабослышащие, слабовидящие, СДВГ, РАС, ЗПР) с конкретными приёмами и формулировками.

6. **Профилактика выгорания.** Учитель перестаёт быть «генератором контента» и становится «режиссёром образовательного события», адаптируя готовый сценарий под свой класс.

### Технические достижения

- **RAG с векторным поиском** — качество сценариев растёт с каждым новым пользователем
- **6 AI-запросов в 2 волны** — баланс скорости и качества
- **4-уровневый JSON-парсер** — устойчивость к «галлюцинациям» AI
- **Полное версионирование** — как в enterprise-системах
- **Адаптивный дизайн** — работает на телефоне, планшете, десктопе
